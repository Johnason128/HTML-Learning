# 练习 2：HTML 文档基础骨架结构 | Practice 2: Basic HTML Document Structure

## 目标 | Objective
- 掌握 HTML 文档的标准基本结构。 | Master the standard basic structure of an HTML document.
- 理解 `<head>`（元数据区）与 `<body>`（可见内容区）的区别与作用。 | Understand the difference and roles of `<head>` (metadata area) and `<body>` (visible content area).

## 代码示例 | Code Example
```html
<!DOCTYPE html> <!-- 声明文档类型为 HTML5 -->
<html>
    <head>
        <meta charset="UTF-8"> <!-- 设置字符编码，防止中文乱码 -->
        <title>网页标题</title>
    </head>
    <body>
        网页主体内容
    </body>
</html>
