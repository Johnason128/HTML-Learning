# 练习 4：HTML 文本格式化标签对比 | Practice 4: HTML Text Formatting Tags Comparison

## 目标 | Objective
- 掌握 HTML 中常用的文本格式化标签。 | Master commonly used text formatting tags in HTML.
- 理解语义化标签（`<strong>`, `<em>`, `<ins>`, `<del>`）与纯样式标签（`<b>`, `<i>`, `<u>`, `<s>`）的区别。 | Understand the difference between semantic tags and presentational tags.
- 学习如何正确使用水平分割线 `<hr>` 和换行标签 `<br>`。 | Learn how to properly use horizontal rule `<hr>` and line break `<br>`.

## 代码结构 | Code Structure
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>网页标题</title>
</head>
<body>
    <h1>前端开发</h1>
    <hr>
    
    <!-- 语义化标签 -->
    <strong>加粗</strong>
    <ins>下划线</ins>
    <em>倾斜</em>
    <del>删除线</del>
    <br>
    
    <!-- 纯样式标签 -->
    <b>加粗</b>
    <u>下划线</u>
    <i>倾斜</i>
    <s>删除线</s>
</body>
</html>
