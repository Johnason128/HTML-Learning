# 练习 5：HTML 图片标签 | Practice 5: HTML Image Tag

## 功能 | Function
- 掌握使用 `<img>` 标签在网页中插入图片。 | Master using `<img>` tag to insert images in web pages.
- 理解 `src` 属性指定图片路径的方法。 | Understand using `src` attribute to specify image path.
- 学习 `alt` 属性提供图片替代文本。 | Learn using `alt` attribute to provide alternative text for images.

## 代码结构 | Code Structure
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>网页标题</title>
</head>
<body>
    <img src="DeepSleep.jpg" alt="">
</body>
</html>
