# 练习 6：HTML 图片标签与替代文本 | Practice 6: HTML Image Tag and Alternative Text

## 功能 | Function
- 掌握使用 `<img>` 标签在网页中插入图片。 | Master using `<img>` tag to insert images in web pages.
- 理解 `alt` 属性在图片加载失败时的替代作用。 | Understand the alternative role of `alt` attribute when images fail to load.
- 学习编写有意义的替代文本以提升可访问性。 | Learn writing meaningful alternative text to improve accessibility.

## 代码结构 | Code Structure
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>网页标题</title>
</head>
<body>
    <!-- 人为错误，用于展示文本替代 -->
    <img src="DeepSeek.jpg" alt="这是一只睡觉的蓝色鲸鱼">
</body>
</html>
